# M3 PDF Lookup Tables

Source document:
- `reference/M3_unorganized/Методика расчета нормативов выбросов от неорганизованных источников.pdf`

This folder contains one CSV per PDF table for `M3_unorganized`.
Files were normalized from the source PDF, not copied from the existing `tables.json`.

Normalization notes:
- Table 3 PDF heading says `k1`, but the section formula context uses this as the local-conditions coefficient.
- Table 4 row `до 9,0` was normalized from a visibly damaged scan row that OCR read as `до 0,0`.
- Table 8 OCR fixes applied from the rendered PDF image:
  - `ОС / 13-25` restored from `3-25`.
  - `Ж / 6-13` restored from `6-3`.
  - `Г / 6-13` restored from `0-13`.
  - `3.3030` restored from `3.3(30)`.
  - `3.3287` restored from `3.328Г`.
  - `5.9723` restored from `5,СУ23`.
  - `Д / 0-3` is missing from the source scan and is omitted.
- Table 14 vehicle rows were split manually from a merged PDF text block.
- Table 16 bulldozer note was normalized to `по сухой породе`.

Generated by `scripts/export_m3_lookup_csvs.py`.
